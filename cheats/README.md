# GoldHEN Cheats for GTA V (v1.56)

## Deployment Path on PS4:
```text
/data/GoldHEN/cheats/json/CUSA00411_01.56.json
```

## How GoldHEN Cheat Manager Loads Cheats:
1. GoldHEN checks `/data/GoldHEN/cheats/json/` for a file named `<TitleID>_<AppVer>.json`.
2. When launching GTA V `CUSA00411` at version `01.56`, it loads `CUSA00411_01.56.json`.
3. Press and hold the **Share** button in-game (or press `L3 + R3` / `D-Pad Right + Square` depending on your shortcut config) to bring up the overlay menu.
4. Toggle your desired cheats in real time!

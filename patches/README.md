# GoldHEN XML Game Patches for GTA V

## Overview
GoldHEN Game Patch (`game_patch.prx`) allows dynamically applying byte patches to game memory when games boot up.

## Deployment Path on PS4:
```text
/data/GoldHEN/patches/xml/GrandTheftAutoV-Orbis.xml
```

## Active Patches in `GrandTheftAutoV-Orbis.xml`:
1. **60 FPS Unlock (`AppVer="01.56"`):** Uncaps the 30 FPS vsync frame pacing cap.
2. **Skip Intro & Legal Logos (`AppVer="mask"`):** Bypasses intro video cutscenes.
3. **Enable Snow in Singleplayer (`AppVer="mask"`):** Activates snow textures and ice handling in Los Santos.

## How to Enable in GoldHEN:
1. On PS4, navigate to **Settings -> GoldHEN -> Plugin Settings**.
2. Set **Enable Plugins Loader** to `ON`.
3. Set **Game Patch** to `ON`.
4. Boot Grand Theft Auto V.
